PHYSICS VERIFICATION

How the physics in this simulator is checked — what runs, against which reference formula, and to what tolerance. This is not marketing copy: where a tolerance is wide, or a check is really a code/UX contract rather than a from-scratch physics derivation, that is said plainly. Nothing below is aspirational — every row maps to a real, currently-passing test file. If a check isn't listed here, it isn't part of the gate.

Reproduce it

bash tests/run.sh

Runs every tests/*.test.mjs file under Node, bare assert, no framework, no build step — currently 39 files, about 2 seconds. Prints PHYSICS GATE: PASS and exits 0 only if every assertion in every file holds. Separately, tests/smoke_playwright.py drives a real browser to catch frame-loop crashes the Node tests can't see — a crash/console-error smoke check, not a physics check, and not covered by the tables below.

The machine-readable gate — physics-gate.yaml

physics-gate.yaml at the repo root formalizes 4 of the invariants below as individually-runnable gate entries — own command, own tolerance, own exit code — rather than lines inside the combined tests/run.sh output. These four are the project's load-bearing physical claims:

INV-PHYS-01longitudinal.regressionLongitudinal 4-force not divided by γ (1000g burn)γ(t)=√(1+(αt/c)²)2%
INV-PHYS-03orbitsAngular-momentum-conserving Kepler elements (e, periapsis, apoapsis)v²=μ(2/r−1/a)1e-3
INV-PHYS-06gravityΦ<0, decreasing with r; weak-field dτ→1 at large rΦ=−μ/r1e-12
INV-PHYS-09relativityAberration formula, round-trip, monotonicity(cp−β)/(1−β·cp)1e-9
The 2% tolerance on INV-PHYS-01 is not a convenience margin — it's the test's own bound at γ≈13, and the file is marked NEVER DELETE, NEVER WEAKEN in its header: if a future 4-force refactor ever divides the longitudinal thrust term by γ, this is the test meant to go red.

Several other files carry their own in-code INV-PHYS-NN labels (10, 11, 12 — see below) that are not yet wired into physics-gate.yaml; they run inside tests/run.sh but don't have an individual entry with their own exit code — a real gap, stated here rather than hidden.

Relevant ADRs

The project's append-only decision log documents several of the choices locked in above. These are the actual ADR.md entry numbers — not the internal "ТЗ item" labels used in a few test-file comments (like orientation's "A6"), which are a separate numbering scheme.

  • ADR-4 — J2000.0 epoch is true TT, not UTC.
  • ADR-7 — Autopilot cancellation: one monotonic counter, one condition, one reader.
  • ADR-8 — bound/unbound classification by specific orbital energy everywhere, never e≥1.
  • ADR-11 — Sound is heard "from inside the hull": no external events audible, Doppler prohibited outright.
  • ADR-12 — AudioContext created lazily, only on a real user gesture; sound off by default.

What this gate does not claim

  • No general relativity (no frame-dragging, no curved-spacetime geodesics beyond the weak-field approximation) — Newtonian gravity + special-relativistic kinematics, by design.
  • Bodies don't perturb each other's orbits — a stated simplification.
  • Transverse thrust is reduced by an extra factor of γ vs longitudinal — the honest relativistic 4-force result, a documented known limitation, not hidden here.
  • A green tests/run.sh is a regression gate, not a proof of absolute correctness — it proves the code still agrees with the formulas and tolerances above. Anything not listed here has no automated check.

ПРОВЕРКА ФИЗИКИ

Как устроена проверка физики в этом симуляторе — что именно гоняется, против какой эталонной формулы и с каким допуском. Это не рекламный текст: там, где допуск широк или проверка на самом деле контракт кода/UX, а не вывод формулы «с нуля», об этом сказано прямо. Ничего ниже не выдаётся желаемое за действительное — каждая строка соответствует реальному, сейчас-зелёному тестовому файлу. Если проверки нет в этом списке — она не часть гейта.

Как воспроизвести

bash tests/run.sh

Гоняет каждый файл tests/*.test.mjs под Node, голые assert, без фреймворка и без сборки — сейчас 39 файлов, около 2 секунд. Печатает PHYSICS GATE: PASS и выходит с кодом 0, только если верны все утверждения во всех файлах. Отдельно tests/smoke_playwright.py гоняет реальный браузер и ловит крэши игрового цикла, которых Node-тесты не видят — это дымовая проверка крэшей/console-ошибок, не физическая проверка, и в таблицы ниже не входит.

Релевантные ADR

Append-only журнал решений проекта документирует часть закреплённых выше решений. Ниже — реальные номера записей ADR.md, не внутренние метки «пунктов ТЗ» из комментариев некоторых тестов (как «A6» у orientation) — это отдельная система нумерации.

  • ADR-4 — эпоха J2000.0 = истинный TT, не UTC.
  • ADR-7 — отмена автопилота: один монотонный счётчик, одно условие, один читатель.
  • ADR-8 — классификация bound/unbound по удельной орбитальной энергии везде, никогда по e≥1.
  • ADR-11 — звук «слышен изнутри корпуса»: внешние события не звучат, Допплер запрещён прямо.
  • ADR-12 — AudioContext создаётся лениво, только по реальному жесту пользователя; звук по умолчанию выключен.

Чего этот гейт не утверждает

  • Нет общей теории относительности (нет frame-dragging, нет геодезических искривлённого пространства-времени за пределами слабопольного приближения) — ньютоновская гравитация + специально-релятивистская кинематика, осознанно.
  • Тела не возмущают орбиты друг друга — заявленное упрощение.
  • Поперечная тяга уменьшена на дополнительный множитель γ относительно продольной — честный релятивистский результат 4-силы, задокументированное известное ограничение, не скрытое здесь.
  • Зелёный tests/run.sh — это регресс-гейт, не доказательство абсолютной корректности: он доказывает, что код по-прежнему согласуется с формулами и допусками выше. У всего, чего нет в этом списке, нет автоматической проверки.
