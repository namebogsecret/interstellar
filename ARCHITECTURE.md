# ARCHITECTURE — interstellar

Границы и потоки. Детали модулей — в CLAUDE.md, постмортемы — в ГРАБЛИ.md,
решения с альтернативами — в ADR.md.

## Слои
```
js/physics/*   чистая физика (СИ, без THREE-рендера, без DOM) — покрыта node-гейтом
js/render/*    рендер и ввод (THREE, DOM) — node-гейтом НЕ покрыт
js/main.js     единственный оркестратор: цикл кадра, floating origin, состояние sim
js/i18n.js     строки; js/data/bodies.js — эфемериды
tests/*.mjs    node-гейт (только physics + чистые функции render)
tests/smoke_playwright.py  единственная фитнес-функция, реально исполняющая цикл кадра
```
Правило слоя: `render/*` не считает физику; `physics/*` не знает о THREE-сцене.
Всё, что можно вынести из `render/*` в ЧИСТУЮ функцию без THREE/DOM, — выносится,
потому что только так оно попадает под node-гейт (ГРАБЛИ #6: гейт зелёный, браузер мёртв).

## Пост-процесс: конвейер кадра
```
RenderPass(scene, БАЗОВАЯ КАМЕРА) → [rel-пасс 2D | rel-пасс cube] → Bloom → Copy→экран
```
Три взаимоисключающих пути рендера (`js/render/renderPolicy.js::resolveRenderPath`):

| path    | условие                       | база RenderPass       | что кропит 90°→60° |
|---------|-------------------------------|-----------------------|--------------------|
| `plain` | relFx выкл                    | camera 60°            | ничего не нужно    |
| `wide`  | relFx вкл, cube выкл          | sourceCamera 90°      | 2D рел-пасс        |
| `cube`  | relFx вкл, cube вкл и готов   | camera 60°            | ничего не нужно    |

**Инвариант кропа (ГРАБЛИ #2):** `renderPass.camera === sourceCamera` ⟺ включён 2D
рел-пасс. Одно выражение, одно место присваивания (`scene.js::applyRenderPath`) —
always-on инвариант не должен зависеть от отключаемого пасса.
