HOW ACCURATE IS IT?

The simulator's relativistic flight code is compared against closed-form reference formulas from special relativity and the weak gravitational field. Every number below is produced by running the project's real modules (ship.js, relativity.js, gravity.js) and comparing with an independently written formula. The tolerance of each row is fixed in advance from the integrator's error estimate, not tuned afterwards.

НАСКОЛЬКО ЭТО ТОЧНО

Релятивистский полёт в симуляторе сверен с эталонными формулами специальной теории относительности и слабого гравитационного поля. Каждое число ниже — результат прогона настоящих модулей проекта (ship.js, relativity.js, gravity.js) против независимо записанной формулы. Допуск каждой строки задан заранее по оценке ошибки интегратора, а не подгонялся потом.

Residuals vs tolerance

Each row: the actual relative error (bar) and the allowed tolerance (tick), log scale. A bar that stays left of its tick passes. Zero errors (exact in double precision) sit at the left edge.

Невязки и допуски

Каждая строка: фактическая относительная ошибка (полоса) и допустимый допуск (риска), логарифмическая шкала. Полоса левее риски — проверка пройдена. Нулевые ошибки (точно в двойной точности) стоят у левого края.

What is not covered

Two checks are marked NOT_COVERED and carry no numbers: the transverse Doppler effect and the aberration/Doppler shader pixels. Their math lives in GLSL, which Node cannot run, so we do not claim a figure for them. The longitudinal gravitational factor is likewise not asserted by the gate — see physics verification.

Reproduce it

bash validation/run.sh          # regenerates validation/results/*
bash validation/run.sh --check  # fails if results drift from the committed ones

Needs only node ≥ 18. Raw data: results.json, table.csv.

Что не покрыто

Две проверки помечены NOT_COVERED и чисел не имеют: поперечный эффект Доплера и пиксели шейдера аберрации/Доплера. Их математика живёт в GLSL, который Node запустить не может, поэтому мы не называем для них точность. Продольный гравитационный фактор тоже не проверяется гейтом — см. проверку физики.

Воспроизвести

bash validation/run.sh          # пересчитывает validation/results/*
bash validation/run.sh --check  # падает, если результаты разошлись с закоммиченными

Нужен только node ≥ 18. Сырые данные: results.json, table.csv.
